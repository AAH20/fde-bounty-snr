# Security Policy

## Authorized use

`fde-bounty-snr` classifies operator-supplied signals for Signal-to-Noise filtering. It does **not** include exploit code, scanners against third-party assets, or unauthorized testing utilities.

## Reporting

If you discover a security issue in this repository itself, email the maintainer via the GitHub profile linked on [a2zsoc.com](https://a2zsoc.com) or open a private security advisory on the GitHub repo.
